# home-work-28
Це домашнє завдання містить дві версії адаптивного слайдера, реалізовані з використанням сучасних підходів у JavaScript:
1. Версія на прототипах з наслідуванням,
2. Версія на класах (ES6 class, extends).


##  Гілки репозиторію

| Гілка              | Опис реалізації                                           |
|--------------------|-----------------------------------------------------------|
| `prototype-version`| Слайдер на основі `function` + `prototype` + наслідування |
| `class-version`    | Слайдер на основі `class` + наслідування + автопауза      |


##  Функціональні можливості

- Слайди зображень
- Кнопки "Вперед" / "Назад"
- Індикатори поточного слайду
- Автоматичне прогортання
- Перемикання слайдів через клавіші (← / →)
- Перетягування мишею
- Підтримка тач-жестів
- Автопауза при наведенні (у версії `class-version`)
- Конфігурація слайдера через об’єкт


## ⚙️ Налаштування (конфігурація)

```js
const config = {
  autoPlay: true,        // Автоматичне прогортання (true/false)
  interval: 3000,        // Інтервал автозміни (мс)
  showIndicators: true   // Показувати індикатори (true/false)
};


 Особливості index.html
HTML-файл містить тільки блок .slides, а всі елементи керування (кнопки, індикатори, автокнопка) створюються динамічно через JavaScript.
